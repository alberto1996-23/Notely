# Your notes, in plain text

Choose **Edit note** to try the live preview, or create a note of your own.

- Write with Markdown.
- Add comma-separated tags to organize ideas.
- Search titles and bodies from the notes list.

## A small code example

```ts
const idea = "Keep learning";
console.log(idea);
```

> Saving writes a Markdown file to the local `notes/` directory.
